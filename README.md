# Портфолио воспитателя

Одностраничный сайт Волковой Анны Викторовны, воспитателя МБДОУ «Детский сад» № 10, г. Солнечногорск.

## Локальный запуск

Откройте `index.html` в браузере или поднимите локальный сервер из этой папки.

## Что где лежит

- `images/gallery/` — фотографии из практики
- `images/awards/` — грамоты и дипломы
- Исходные материалы заказчика в репозиторий сайта не входят и не изменяются

## Контакты на странице

Телефон и почта взяты с титульного листа проекта детского сада. Личный телефон воспитателя в материалах не указан.

## Домен

Перед публикацией подставьте реальный адрес сайта в `sitemap.xml`. В `index.html` нет абсолютного адреса предыдущего проекта: `og:url`, `canonical` и `og:image` нужно добавить, когда будет известен домен.

## Минификация

```bash
npm install
npm run minify
```

После правок `styles/style.css`, `styles/slider.css` или `scripts/script.js` пересоберите `*.min.*`: страница подключает минифицированные файлы.
